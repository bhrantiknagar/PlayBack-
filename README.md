# PlayBack 🎵

A sleek, high-performance music streaming web application.

## Quick Start

### URL
```
URL = https://playback-theta.vercel.app
```

### Tech Stack
- **Frontend**: React + Vite
- **Backend**: Node.js + Express
- **Database**: MongoDB Atlas
- **Storage**: Cloudinary
- **Deployment**: Vercel (Frontend), Render (Backend)
